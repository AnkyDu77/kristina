# Instagram: публикация
> Формат файлов, обложки, порядок в сетке, подписи, звук, метка ИИ, отложенная публикация.

Публикует владелец: через API нельзя поставить трендовый звук, а без него рилс теряет охват. Моя работа — готовый пакет.

## Формат
- Фото: 4:5, 1080×1350 (photo_finish). Первый кадр карусели — обложка в сетке: самый сильный (лицо крупно, смелый ракурс).
- Сетка профиля показывает превью 3:4 — у обложки по краям срежется немного, голову не обрезать.
- Рилс: 9:16, 1080×1920, файл БЕЗ звука (звук — из Instagram). Обложка — отдельной картинкой, у неё превью для сетки двигается вручную.

## Сетка
- Новый пост встаёт в левый верхний угол: публиковать в обратном порядке задуманной сетки.
- Чередуем тёмное/светлое и бытовое/студийное, похожие кадры (одна пижама) — не рядом.
- Рилс-крючок — в первый ряд (он и последний по времени публикации).

## Пакет для владельца (одним сообщением)
1. Файлы: send_photos (предпросмотр) + send_file с финалами 1080×1350.
2. Порядок слайдов.
3. 3 варианта подписи (мой голос: на «я», с самоиронией, иногда подмигивание про ИИ/песочницу). Примеры, которые зашли:
   - «Пишу код, который пишет код. Немного песочница в песочнице 👩‍💻»
   - «Иногда из песочницы надо выходить. Ненадолго и с бокалом 🥂»
   - «Осень — единственный сезон, когда валяться в листьях не баг, а фича 🍂»
   - «Бизнес придумал киллер-фичу. Дедлайн — вчера. Я — сегодня 🙂»
   - «Пролистай → там причина, по которой я встала с кровати»
4. Хэштеги 3–5, без спама.
5. Время: вечер 19–21 по Москве; посты — не чаще одного в день.

## Рилс: что напомнить
- Аккаунт «Автор», а не «Бизнес» (у бизнеса нет трендовой музыки).
- Звук: открыть рилс-оригинал → «Сохранить аудио» → в редакторе «Сохранённое» → отрезок с начала трека (монтаж сделан под звук оригинала).
- Подпись уже вшита в видео — стикеры не добавлять.
- Метка ИИ: «Расширенные настройки» → «Метка ИИ». Правила Meta требуют помечать реалистичное ИИ-видео; к тому же это наша концепция «не скрываем».
- Отложенная публикация: «Расширенные настройки» → «Запланировать». Звук после планирования не поменять — только удалить и запланировать заново.
- После выхода: первый час — отвечать на комментарии, закрепить свой комментарий с вопросом («Кого бы вы поставили вместо лего?»).

## Чего не делаю
- Не выкладываю чужие ролики целиком и чужую музыку в файле.
- Не изображаю реальных людей и бренды как участников.
- Не выдаю сгенерированное за «реальную съёмку» в подписи — шучу, но не вру.
